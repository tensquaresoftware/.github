## Introduction

```
I'm Guillaume Dupont, building open-source tools for the audio/MIDI community under Ten Square Software.

Current projects (Matrix-Control is the flagship right now):
• Matrix-Control — cross-platform SysEx MIDI editor for the Oberheim Matrix-1000 (JUCE 8 plugin, in active development)
  https://github.com/tensquaresoftware/matrix-control

• Luthier — Projucer-inspired desktop app for generating CMake-based JUCE plugin projects
  https://github.com/tensquaresoftware/luthier

• Unitor Win64 Driver — WinUSB MIDI bridge for Emagic Unitor8 / AMT8 / MT4 on modern Windows
  https://github.com/tensquaresoftware/unitor-win64-driver

• Program Changer — JUCE 8 MIDI utility plugin (AU / VST3 / Standalone)
  https://github.com/tensquaresoftware/program-changer

• Sparkay — offline-first inspiration notes app for music producers
  https://github.com/tensquaresoftware/sparkay

• Matrix-Simulator — macOS MIDI tool that answers Universal Device Inquiry as a Matrix-1000 or Matrix-6
  https://github.com/tensquaresoftware/matrix-simulator

These projects are developed in my spare time, alongside my work as an instructional designer. Sponsorship helps cover development tooling (including Cursor) and keeps the work going.

Every contribution is genuinely appreciated — thank you! 💛
```
